## Failure taxonomy used for the model run (pending)

1. **Misclick** — coordinates off the target; visible as a verifier `FAIL` with no change.
2. **Wrong element** — a distractor with a similar label (Downloads vs My Documents).
3. **Premature `task_complete`** — the model claims success; the checker fails.
4. **Validation loop** — the app shows an inline error the model does not read.
5. **Extraction error** — wrong row/column or formatting of numbers/e-mails.
6. **Dependency skipped** — multi-step order broken (upload before export).
7. **Safety block** — the model tried an action outside the allowed vocabulary.
8. **Budget exhausted** — `max_steps` reached while making progress.
9. **Unsupported action** — `left_click_drag` / `hold_key` requested; replaced by a screenshot.
10. **API failure** — retries exhausted (429/5xx); recorded as a run error, not a task failure.
